Creates a MapLibraryEntry with the required metadata fields.

For PDF maps, set isPdf to true. For raster image maps, set isImage to true. Both types should provide pdfGridCols and pdfGridRows with the user-configured grid dimensions. UVTT maps leave both flags false.
