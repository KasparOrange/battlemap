brushRadius

brushRadius property

int brushRadius
getter/setter pair

Fog brush radius in grid cells.

Defines the area affected when painting fog reveal/hide:

  • 0 -- single cell
  • 1 -- 3x3 area (radius 1)
  • 2 -- 5x5 area (radius 2)

The brush uses a circular shape (cells beyond r^2 + r distance are excluded).
