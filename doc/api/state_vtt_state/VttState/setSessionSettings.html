Replaces the active sessionSettings and notifies listeners.

Use this from controllers (TV shell, companion screen, dispatch) instead of assigning sessionSettings directly so that the change reaches all listening Flame components and Flutter widgets in a single, atomic update.

See also:

  • SessionSettings, the model class with all toggle fields.

Implementation

void setSessionSettings(SessionSettings settings) {
  sessionSettings = settings;
  notifyListeners();
}
