CameraSnapshot

CameraSnapshot class

A snapshot of a camera transform plus the viewport it looks through.

Sent by the TV inside every vtt.fullState (camera object) and used on the phone to draw the TV's visible area as a dashed rectangle (TvViewportComponent) and to implement "match TV" / "send view".

See also:

  • VttGame.getCameraState, which produces the JSON form.
  • VttGame.setTvViewport, which stores the snapshot on the phone.
