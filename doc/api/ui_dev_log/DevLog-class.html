DevLog

DevLog class

Singleton in-memory log buffer for the DevScreen.

Captures timestamped messages and notifies registered listeners so the developer screen can update in real time. The buffer is capped at maxLines entries; oldest lines are discarded when the cap is exceeded.

Usage:

DevLog.add('Companion: paired with TV');

See also:

  • DevScreen, which renders these log lines on screen.
