DmCallbacks

DmCallbacks class

Bundle of callbacks for every action the DM control panel can trigger.

Each screen that hosts a DmControlPanel provides its own implementations. In networked mode (VttCompanionScreen), callbacks send commands through the VttRelayClient. In local mode, callbacks act directly on VttState and VttGame.

See also:

  • DmControlPanel, the widget that invokes these callbacks.
