Map<String, dynamic> toJson()

Serializes this token to a JSON-compatible map.

The color is encoded as an 8-character ARGB hex string. Combat metadata (name, maxHp, currentHp, conditions) is always included for forward compatibility.

Implementation

Map<String, dynamic> toJson() => {
      'id': id,
      'label': label,
      'color': color.toARGB32().toRadixString(16).padLeft(8, '0'),
      'gridX': gridX,
      'gridY': gridY,
      'name': name,
      'maxHp': maxHp,
      'currentHp': currentHp,
      'conditions': conditions.toList(),
    };
