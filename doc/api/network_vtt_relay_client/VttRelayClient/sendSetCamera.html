Moves the TV camera to an absolute transform.

camera holds x, y (world center), zoom and angle (radians) — the phone's own camera when "link TV to phone" is on or "send view" is tapped. Extra keys (vw, vh) are ignored by the TV.

Implementation

void sendSetCamera(Map<String, double> camera) => _send({
      'type': 'vtt.setCamera',
      'x': camera['x'],
      'y': camera['y'],
      'zoom': camera['zoom'],
      'angle': camera['angle'],
    });
