Map<String, dynamic> toJson()

Serializes this session to a JSON-compatible map.

Timestamps are encoded as ISO 8601 strings. Token and stroke data are stored as raw JSON maps (already serialized by their respective toJson methods). The isPdfSession flag is always included for forward compatibility.

Implementation
